# Documentation Archive

ဤ directory အောက်ရှိဖိုင်များသည် historical evidence သို့မဟုတ် superseded material ဖြစ်သည်။ လက်ရှိ implementation instruction အဖြစ် မသုံးပါနှင့်။ Active documentation entry point သည် [`../README.md`](../README.md) ဖြစ်သည်။

| Directory / File | Contents |
|---|---|
| `audits/` | အချိန်တစ်ခုအတွင်း ရရှိခဲ့သော audit/baseline reports (UAT artifacts, Phase A readiness report, pre-installer baseline) |
| `completed-phases/` | ပြီးခဲ့သော phase များ၏ completion reports; SHA/test claims များသည် historical snapshot သာဖြစ်သည် |
| `superseded-plans/` | version အသစ်ဖြင့် အစားထိုးထားသော plans (Windows installer plan v1, initial plan, early `pos-resale-plan/`) |
| `legacy-ops/` | အစောပိုင်း Hostinger pilot cutover နှင့် backup-restore drills များ (`hostinger-pilot/`) |
| `legacy-prompts/` | [`../prompts/AI_AGENT_QA_PLAYBOOK.md`](../prompts/AI_AGENT_QA_PLAYBOOK.md) ထဲသို့ပေါင်းထားသော prompt fragments နှင့် early UAT testing agent prompts (`testing-agents/`) |
| `source-of-truth-history/` | မူလ Source-of-Truth draft များ (v1, v2, AlinnThit 2026-07-31) |
| `deployment-runbook.md` | အစောပိုင်း site deployment runbook မှတ်တမ်း (archived 2026-08-13) |

Archive ထဲမှဆုံးဖြတ်ချက်တစ်ခုကို ပြန်သုံးမည်ဆိုပါက current code၊ tests နှင့် active documents နဲ့ ပြန်စစ်ပြီးမှ အသုံးပြုရမည်။
