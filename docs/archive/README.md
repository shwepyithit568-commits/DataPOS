# Documentation Archive

ဤ directory အောက်ရှိဖိုင်များသည် historical evidence သို့မဟုတ် superseded material ဖြစ်သည်။ လက်ရှိ implementation instruction အဖြစ် မသုံးပါနှင့်။ Active documentation entry point သည် [`../README.md`](../README.md) ဖြစ်သည်။

| Directory | Contents |
|---|---|
| `audits/` | အချိန်တစ်ခုအတွင်း ရရှိခဲ့သော audit/baseline reports |
| `completed-phases/` | ပြီးခဲ့သော phase များ၏ completion reports; SHA/test claims များသည် historical snapshot သာဖြစ်သည် |
| `superseded-plans/` | version အသစ်ဖြင့် အစားထိုးထားသော plans |
| `legacy-prompts/` | [`../prompts/AI_AGENT_QA_PLAYBOOK.md`](../prompts/AI_AGENT_QA_PLAYBOOK.md) ထဲသို့ပေါင်းထားသော prompt fragments |

Archive ထဲမှဆုံးဖြတ်ချက်တစ်ခုကို ပြန်သုံးမည်ဆိုပါက current code၊ tests နှင့် active documents နဲ့ ပြန်စစ်ပြီးမှ အသုံးပြုရမည်။
